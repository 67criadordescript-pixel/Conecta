CONecta 3.1 — implantação no Render

1. Envie TODOS os arquivos deste pacote para a raiz do repositório GitHub (package.json, server.js, index.html, test.js, README.md, render.yaml e .gitignore).
2. No Render, crie/atualize um Web Service ligado ao repositório.
3. Build Command: npm install
4. Start Command: npm start
5. Node: o projeto pede Node.js 20 ou superior; o arquivo .node-version indica 22.
6. Health Check Path: /healthz
7. Aguarde deploy concluído. Teste o site, /terms, /privacy e /healthz.
8. Antes de divulgar, preencha o contato e a identidade do responsável nos documentos, revise os termos e a política com profissional jurídico e execute npm test (aba Shell/CI se disponível).

Variáveis opcionais (configure `CONTACT_EMAIL` com um endereço real e monitorado antes de publicar):
MAX_CLIENTS=250
MAX_CONNECTIONS_PER_IP=12
MAX_DEVICES_PER_ROOM=10
MESSAGE_LIMIT_PER_SECOND=8
ALLOWED_ORIGINS=https://seu-dominio.example,https://seu-servico.onrender.com

Não configure ALLOWED_ORIGINS com domínios que você não controla. Se definir a variável, inclua cada origem exata usada pelos usuários, com https:// e sem caminho.
