CONECTA 3.1 — LEIA-ME

Para publicar no GitHub + Render, leia primeiro README.md e DEPLOY-RENDER.txt.
Para configurar um domínio protegido pela Cloudflare, leia CLOUDFLARE.md.

Arquivos principais:
- index.html: interface web
- server.js: servidor HTTP e WebSocket
- package.json: dependências e comandos
- test.js: testes automatizados (execute após instalar dependências com npm install)
- /terms: termos de uso
- /privacy: política de privacidade
- /healthz: health check

Importante: os documentos legais são modelos e precisam de revisão e dados reais do responsável. Cloudflare requer domínio próprio e configuração no painel. Não há criptografia ponta a ponta nem análise antivírus. Não divulgue o serviço antes de configurar o contato e revisar os documentos.
