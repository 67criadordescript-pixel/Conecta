CONECTA — VERSÃO PARA GITHUB + RENDER

Para publicar sem usar comandos:
1. Crie um repositório no GitHub chamado Conecta.
2. No site do GitHub, use Add file > Upload files e envie os arquivos desta pasta.
3. Em render.com, crie um Blueprint e conecte o repositório. O arquivo render.yaml configura o serviço.
4. Abra o link HTTPS gerado pelo Render no PC e no Galaxy Tab.
5. Digite o mesmo código de sala em ambos e clique em Conectar. O endereço do servidor é preenchido automaticamente.

IMPORTANTE: não use GitHub Pages sozinho. Ele não executa o servidor WebSocket necessário para chat e envio de arquivos. Use o Render ligado ao GitHub.

Código da sala: 4 a 32 caracteres, usando letras sem acentos, números, hífen ou sublinhado. Compartilhe-o apenas com quem deve entrar na sala.

Arquivos: index.html, server.js, package.json, render.yaml e este guia.

No Windows local, iniciar.bat continua disponível (requer Node.js LTS). Para usar o link online, não é necessário instalar nada no tablet.

Segurança: mensagens/arquivos passam pelo servidor e não têm criptografia ponta a ponta. Não use dados sensíveis. Arquivos limitados a 8 MB.
